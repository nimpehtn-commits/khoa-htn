# Khoa Hóa thực nghiệm – bản cài trên máy

Trang vỏ để cài App Quản lý Khoa Hóa thực nghiệm từ Chrome/Edge (Windows, Android, iPhone) và dùng khi tạm mất mạng.
Giao diện và dữ liệu lấy từ máy chủ Google Apps Script của Khoa; kho này không chứa dữ liệu.

Mở: https://nimpehtn-commits.github.io/khoa-htn/ → biểu tượng "Cài đặt" trên thanh địa chỉ Chrome.
